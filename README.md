# 智慧社区/小区小程序 (Community SaaS Mini-Program)

本项目是一个基于微信小程序的多小区 SaaS 社区服务平台。采用**“基础功能免费 + 增值功能开通”**的 Freemium 模式，兼具**物业服务刚需**、**邻里温情社交**与**周边便民商圈**。

## 🚀 核心技术路线与选型

* **前端框架**：Uni-app (Vue3) / 微信原生小程序
* **后端 & 数据库**：微信小程序云开发 (CloudBase Node.js 云函数 + 云数据库)
* **付费模式**：MVP 阶段自研 + 不接入微信支付（线下扫码/凭证打卡/面交闭环）
* **租户隔离**：全表 `community_id` 逻辑隔离 + `X-Community-Id` 请求头注入
