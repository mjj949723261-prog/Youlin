# 03. 商业模式与功能分级规划

## 一、 功能划分体系 (基础免费 vs 后期定制收费)

根据“**试点推广 ➔ 社区普及 ➔ 辅助功能收费**”的发展战略，功能精准划分为两大体系：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     社区/小区小程序功能分级矩阵                          │
└─────────────────────────────────────────────────────────────────────────┘
  【基础功能 (Free Tier - 免费开通/推广引流)】
   ├── 1. 公告通知 ── 社区(街道)公告、业委会公示、物业紧急通知
   ├── 2. 邻里发帖 ── 交流动态、吐槽建议 (支持私密直通与公开讨论)
   ├── 3. 邻里求助 ── 急借工具、急用药、临时代遛狗/喂猫
   ├── 4. 邻里活动 ── 亲子活动、约跑组局、户外运动
   ├── 5. 闲置二手 ── 同小区物品赠送、二手面交
   └── 6. 房屋出租 ── 小区内房屋直租、找室友/合租信息

  【辅助/定制功能 (Premium Tier - 后期对接/收费项目)】
   ├── 1. 物业费/停车费在线缴纳与自动对账 (财务结算)
   ├── 2. 智慧门禁与动态二维码/近场开门 (IoT对接)
   ├── 3. 业主大会线上防篡改电子表决/投票 (合规表决)
   ├── 4. 社区团购与周边便民商圈自动分账 (商业抽成)
   └── 5. 高级 BI 数据大盘与工单超时预警 (管理增强)
```

## 二、 三阶段推广落地路线图 (Rollout Strategy)

```
[阶段一: 1个小区MVP试点] ──► [阶段二: 社区内多小区推广] ──► [阶段三: 跨社区跨区域SaaS扩张]
 (验证邻里发帖与高频留存)     (验证社区-小区一对多架构)      (规模化变现与收费功能对接)
```

### 1. 阶段一：试点阶段 (Single小区 MVP)
* **核心目标**：单小区打透，验证“邻里求助、闲置面交、吐槽”的高频留存率。
* **部署**：仅使用基础免费功能，零成本招募第一个小区合作。

### 2. 阶段二：社区内扩展 (Sub-district Expansion)
* **核心目标**：向所在社区（街道）下的其他小区快速复制。
* **部署**：启用“社区（街道）”管理者视角，社区可以向管辖的所有小区一键下发政策通知。

### 3. 阶段三：跨社区扩张与增值变现 (Cross-Community & Monetization)
* **核心目标**：向更多社区推广，并开始对接物业收费项目。
* **部署**：开启物业开门、在线缴费、商家团购分账等定制付费模块。
