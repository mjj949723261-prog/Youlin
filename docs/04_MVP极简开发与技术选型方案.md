# 04. MVP 极简开发与技术选型方案

## 一、 技术栈选型

* **前端**：Uni-app (Vue3) + `uni-ui` 组件库
  * 理由：开发速度极快，组件库丰富，跨端支持好。
* **后端与数据库**：微信小程序云开发 (CloudBase)
  * 理由：免 Linux 服务器运维、免配置 Nginx/域名/SSL，内置云数据库与云函数，自动静默获取 `OPENID`。

## 三、 项目源码目录规范

推荐的前端代码目录划分：

```
src/
├── api/                  # 接口封装 (带 X-Community-Id)
├── components/           # 全局通用组件 (小区选择器、身份标签)
├── store/                # Pinia 全局状态 (user, community)
├── pages/                # 主包页面 (首页、小区选择、认证、个人中心)
└── subpackages/          # 业务分包
    ├── property/         # 报修、缴费、访客
    ├── social/           # 邻里圈、失物招领
    └── mall/             # 便民黄页、团购
```
